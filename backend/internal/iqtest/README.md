# 账号页的智商测试

账号管理页提供以下入口，全部使用 `/admin/iqtest` 的真实记录：

- 勾选账号后点击 **批量智商测试**，每个选中账号依次执行糖果和鹈鹕骑自行车 SVG 测试。默认使用 GPT-6 Astra（`gpt-6-astra`）和服务器内置题目，不创建定时计划。账号间默认并发 3 个。
- 页面显示任务编号、已完成测试项数、通过 / 质量失败 / 请求异常 / 跳过数量。任务在后台执行，同一浏览器标签页刷新后恢复进度；“运行记录”可查询历史批次。
- “查看结果”支持分页，每条记录可打开其真实输出，SVG 项可预览对应图片。
- 所有糖果 / SVG 检查在模型留空时使用 GPT-6 Astra；新计划预填此模型，显式填写其他模型仍可覆盖默认值。
- 顶部 **测试计划** 进入智商测试页的“测试计划”标签，可创建或编辑定时计划。

请求失败不会自动重新提交批次。若提示无法确认提交，请先检查运行记录，避免重复消耗额度。不可用账号由现有执行器记录跳过原因；模型请求错误与答案质量失败分别处理。

## 统计与筛选

统计栏覆盖所有未删除账号，不受搜索、分组或当前分页影响。每个账号仅归入一个类别，按两项测试各自最近一次结果判断，优先级如下：

1. 任何一项最近结果为 `quality_fail` → 质量异常。
2. 否则，任何一项为 `infra_error` → 请求异常。
3. 否则，至少一项为 `pass` → 质量正常。
4. 无结果，或仅有跳过结果 → 尚未测试 / 已跳过。

这与基于连续失败策略的历史标记是不同的指标。账号列表“智商状态”列仍只依据最近一次糖果测试判断正常 / 降智。

质量筛选使用 `iq_quality=quality_fail|infra_error|normal|untested`，数据库在计数和分页之前应用，支持与平台、分组等条件组合。全选筛选结果、批量编辑、导出和上游倍率快照均传递此条件。

`GET /api/v1/admin/iqtest/summary` 返回全局分类计数；`GET /api/v1/admin/iqtest/runs/:id` 在运行中返回已保存结果的实时计数。接口沿用管理员认证。

质量标记不自动改变账号启用状态。现有上游 403 / 429 等运行状态处理仍由原执行流程负责。

## 账号列表排序

- `sort_by=iq_status` 按智商状态排序，以最近一次糖果测试为准：升序为降智、正常；降序为正常、降智。待确认（未测、跳过或请求异常）始终在末尾，SVG 结果不参与此列排序。排序在数据库分页前完成。
- 点击账号页的“手动排序”，拖动全部账号（也可用上下按钮），再“保存并应用”。显示顺序保存在独立的 `iq_account_display_order` 表，不修改账号调度优先级、凭据或账号状态。筛选、分页后仍使用同一顺序，新账号排在已保存的账号之后。
- 管理员 API：`GET /api/v1/admin/iqtest/account-order` 返回账号 id、名称、平台及顺序版本；`PUT` 提交完整 `account_ids` 和 `revision`。保存使用事务与互斥锁，拒绝重复、缺失、未知 ID；列表或顺序已变化时返回 409，界面要求刷新后重试。
- 手动排序入口显示最多 10,000 个未删除账号。当前排序方式记在浏览器中，手动顺序本身保存在服务器；点击其他表头可临时使用该列排序，再进入手动排序保存应用即可切回。

## 鹈鹕视觉评分（pelican-vision-v1）

鹈鹕生成后会先做安全/格式检查，再用内嵌的 resvg 渲染为 PNG，最后向**另一可用 OpenAI 账号**的 GPT-6 Astra 发送实际 PNG 图片和固定评审标准。评审账号优先选择最近糖果通过的账号，排除被测账号、糖果失败/已标记账号以及不可用账号；不回退到被测账号自评。没有独立评审账号、渲染失败、请求失败或评分 JSON 无效时，记录 `infra_error/review_error`，不判通过，不累计质量失败。

- 鹈鹕辨识度 25 分，自行车结构 25 分，骑乘关系 30 分，轮廓完整性 10 分，可读性 10 分。
- 总分至少 75，前三项分别至少 15/15/18，且无严重缺陷，才能通过。通过条件由服务器执行，不采纳模型自行声称“通过”。
- 严重缺陷包括鹈鹕不可辨、自行车关键结构缺失、骑乘关系不存在、明显错接/畸形/实心块遮挡等。
- 保存每项理由、严重缺陷、评审模型/账号 ID、标准版本、图片 SHA-256 和尺寸。AI 评审不是绝对真值，应结合理由和原图复核。
- 旧算法的分数只反映元素/颜色/圆形计数，不能代表画面质量。迁移将旧 SVG `pass` 改为未视觉审核（`skipped/visual_review_required`），保留原图和 `metrics.legacy_structure_score`，修正运行统计并清空旧 SVG 通过历史；糖果记录不受影响。
- 糖果测试通常 1 次调用；鹈鹕测试通常 2 次调用（生成 + 评审）。两次调用均计入 `max_requests_per_run` 和请求统计。审核失败后不重复调用，不隐式切换重试。
- 渲染器无主机文件/网络权限，单次最长 20 秒、WASM 内存上限 256 MiB、最长边 768 像素，串行渲染避免占用过多内存。服务器原生部署不需要另装浏览器或图片工具。
